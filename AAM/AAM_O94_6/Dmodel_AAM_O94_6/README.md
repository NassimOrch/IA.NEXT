# AAM O94.1 — runtime et preuves

La notice complète d'usage se trouve dans `README_O94_1_FR.md`. Pour démarrer l'interface locale, utiliser `run_AAM_O94_1.bat` (Windows), `run_AAM_O94_1.ps1` (PowerShell) ou `run_AAM_O94_1.sh` (Linux/macOS). Pour la CLI : `python -m aam_o93 --help`.

Cette version réunit l'intégration déclarative de modèles, le RAG/mémoire hérités, l'orchestration locale, les briques de base et un premier adaptateur de capture entrée/sortie en boîte noire. Les résultats restent bornés aux reçus listés dans `logs/O94_1` et `registre_prouves_O94_1.json`. Ce paquet ne déclare pas le clonage universel, la capture générique caméra/GUI/vidéo/capteurs, ni un entraînement réel de poids externes comme des capacités déjà démontrées.
