# Protocole de vérification général

Une provenance complète ne suffit pas à établir qu’un problème est résolu.

1. Observation : produire des unités de données avec provenance.
2. Synthèse : construire un candidat.
3. Vérification documentaire : contrôler provenance/couverture.
4. Mémoire : admettre uniquement l’insight documentaire vérifié.
5. Résolution complète : exiger un vérificateur de domaine indépendant.

Le moteur ne transforme pas une phrase telle que « ce problème est résolu » en résolution du problème.
