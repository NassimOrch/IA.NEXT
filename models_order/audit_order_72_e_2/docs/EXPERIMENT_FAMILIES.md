# ORDER72 experimental families

The audit separates families so that success on one micro-domain cannot be mistaken for generality:

1. exact public finite optimization
2. choice / no-choice equivalence
3. permutation and label mutation
4. arithmetic
5. logic
6. sequences
7. sorting / partition
8. graphs / relations
9. planning
10. constraints
11. symbolic transformations
12. spatial transformations
13. causal interventions
14. counterexample reasoning
15. partial observability
16. associative key-value retrieval
17. WM-null causal ablation
18. resource-bound search
19. hidden-oracle injection tests
20. frozen-weight integrity tests

The O71 WM role study additionally uses a 12-family held-out transition probe and a depth-3 causal search benchmark.
