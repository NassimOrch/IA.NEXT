# Contenu du paquet portable EX8 v010

Le paquet portable contient les expériences complètes v010 (résultats, checkpoints, prédictions, journaux, scripts, configurations, tests, rapports, figures, manifests), le prompt EX8, les entrées train/validation autorisées, les ancres v001 vérifiées et les références v009 utiles.

Pour réduire les doublons volumineux, il n'inclut pas les répertoires sources extraits `inputs/SOURCE_PROJECTS`, `inputs/LAST_SOURCES_3` et `inputs/EX8_V001_FULL`. Les sources et archives originales restent conservées intégralement dans le workspace fixe `EX8/versions/sondes_ex8_v010__2026-11-01/inputs/` et sont identifiées par hash dans `checksums/SHA256SUMS.txt`, `deliverables/SOURCE_ZIP_AUDIT.csv` et `deliverables/V010_SOURCE_ARCHIVES_CRC_AUDIT.csv`. Le rapport d'audit des sources résume leur lignée.

Le paquet portable n'est donc pas une copie complète des archives historiques ; c'est le paquet de résultats/reproductibilité nécessaire pour relire et vérifier les expériences v010.
