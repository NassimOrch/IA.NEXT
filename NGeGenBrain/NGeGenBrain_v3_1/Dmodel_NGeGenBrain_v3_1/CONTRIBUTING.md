# Contribution et protocole de changement

1. Décrire l'exigence, son statut épistémique et ses dépendances.
2. Ajouter les tests avant ou avec le code ; inclure un test de contre-exemple si le comportement est scientifique.
3. Enregistrer la graine, les empreintes du modèle/données et la commande de test.
4. Ne pas modifier rétroactivement les résultats bruts. Une nouvelle analyse reçoit un nouvel identifiant.
5. Distinguer le comportement observé de l'interprétation et garder les hypothèses concurrentes.
6. Exécuter les tests V2 et la suite héritée V1 si un chemin de compatibilité est modifié.
7. Un résultat de reconstruction doit expliciter son domaine, les métriques hors-échantillon et les dépendances au modèle source.
